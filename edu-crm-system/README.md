# EduCRM - Система управления онлайн-образованием

## Описание
**EduCRM** — это учебный проект (курсовая работа), представляющий собой платформу для управления онлайн-образованием с элементами CRM-системы. Проект разработан как аналог Moodle с упрощенным функционалом для демонстрации навыков веб-разработки, работы с базами данных и проектирования информационных систем.

## Цель проекта
Разработка веб-приложения для автоматизации процессов онлайн-обучения, включая управление курсами, студентами, преподавателями и учебными материалами в рамках курсовой работы.

## Возможности
- ✅ Регистрация и авторизация пользователей (студенты, преподаватели, администраторы)
- ✅ Создание и управление курсами
- ✅ Запись студентов на курсы
- ✅ Отслеживание прогресса обучения
- ✅ Разделение прав доступа по ролям
- ✅ Адаптивный дизайн

## Установка

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 2. Запуск приложения
```bash
python app.py
```

### 3. Доступ к приложению
Откройте в браузере: http://localhost:5000

## Учетные данные по умолчанию

## Структура проекта
```
edu-crm-system/
├── app.py                 # Основной файл приложения (точка входа)
├── requirements.txt       # Зависимости Python для установки
├── instance/             # Папка с базой данных (SQLite)
├── templates/            # HTML шаблоны интерфейса
│   ├── base.html         # Базовый шаблон
│   ├── index.html        # Главная страница
│   ├── login.html        # Страница входа
│   ├── register.html     # Страница регистрации
│   ├── dashboard*.html   # Панели управления для разных ролей
│   ├── courses.html      # Список курсов
│   ├── course_detail.html# Детали курса с темами
│   └── create_*.html     # Формы создания (курсов, тем, материалов)
└── static/              # Статические файлы (CSS, JS, изображения)
    └── css/
        └── style.css     # Основные стили приложения
```

## Информация о проекте
- **Тип работы:** Курсовой проект
- **Предметная область:** Онлайн-образование, CRM-системы
- **Стек технологий:** Python, Flask, SQLite, HTML/CSS, Jinja2

## Роли пользователей

### Администратор
- Просмотр статистики платформы
- Создание курсов
- Управление пользователями

### Преподаватель
- Создание и редактирование курсов
- Просмотр enrolled студентов
- Добавление уроков

### Студент
- Просмотр доступных курсов
- Запись на курсы
- Отслеживание своего прогресса

## Технологии
- **Backend:** Python, Flask
- **База данных:** SQLite (через SQLAlchemy)
- **Frontend:** HTML, CSS, Jinja2 templates
- **Аутентификация:** Flask-Login
